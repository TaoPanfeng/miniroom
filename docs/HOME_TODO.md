# 我的家 · 落地与验收清单

> 原则：仅使用 miniroom 的 main 分支，原书房和照片小屋功能与数据不受影响。手绘面积约 50㎡，不是测绘图，不把精确住址或私人手绘文件公开。

## P0 · 先攻克的结构
- [x] 拆分主卧、阳台、次卧、客厅、卫生间、厨房、入户走廊七块实际空间
- [x] 不规则房屋外轮廓；隔墙与房门按草图落位；剖面能看到内部
- [x] 引体向上横杆及两侧固定支撑，与主门之间顶部储物夹层分别建模
- [x] 夹层靠引体架侧为开放口、上方有顶板，而不是封底吊柜
- [x] 「我的家」作为第三间小屋且默认打开，旧房间的数据不迁移、不覆盖

## P1 · 可并行的家具和界面
- [x] 主卧：床、枕头、衣柜、吊灯、阳台晾衣杆与空调外机
- [x] 次卧：儿童床、写字桌、椅子、电子琴、床头书柜
- [x] 客厅：桌椅、书柜、冰箱；Wi-Fi 路由器摆在冰箱顶
- [x] 厨房：操作台、水槽、灶台、抽油烟机
- [x] 卫生间：马桶、洗衣机、洗手池、淋浴区
- [x] 「我的家」隐藏书房左侧控制面板，房屋模型居中放大
- [x] 拖动旋转、缩放、俯视、视角重置、墙体剖切、点击门开合
- [x] WebGL 不可用时 Canvas 户型示意回退
- [x] 进入书房才启动原书房 WebGL，避免同时占用两个渲染上下文

## P2 · 联调与发布验收
- [x] JavaScript 语法、本地依赖、静态资源在构建时检查
- [x] 户型面积估算及七块房间不重叠的静态校验
- [x] 三间小屋共用一个切换器，不修改既有书房/照片墙存储结构
- [ ] 真实墙体尺寸、门窗宽度、各门朝向（当前按手绘示意推断）
- [ ] 用真实量尺校准家具间距和尺寸（当前为可交互概念还原）

## 需复测的操作
1. 首次访问和刷新都默认进入「我的家」，左侧没有书房氛围/计时卡片。
2. 拖动、缩放、恢复视角、俯视及剖切切换无空白或异常。
3. 引体架横杆顶部能看到储物口，不应有封死的底板。
4. 三房切换后，原书房笔记、相框、计时和照片小屋的内容不变。
5. 退出「我的家」后渲染暂停；返回能恢复，控制台无异常。
6. 手机窄屏可操作，页面无横向溢出，Canvas 兼容模式能显示户型。
7. GitHub Actions 的 check、build、deploy 全通过，只保留 main。
